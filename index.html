Chat Plays Steve

Steve is controlled from the YouTube chat. Below: every chat command, every donation event and its price, and a map of the world.

About

A normal Minecraft survival world. Nobody plays Steve — the chat does, and donations throw events at him.

The game

  • Minecraft Java Edition 1.21.1, vanilla survival: no modded blocks, items or mobs.
  • Mods only show things on screen and connect the YouTube chat and donations to the game.
  • Steve always looks like the classic Steve, whatever skin the account has.

Death

  • Steve respawns by himself after a 5 second countdown.
  • An oak sign marks the spot.
  • Items drop as usual — go back and pick them up.

Events

  • An event happens once its line on screen has settled.
  • Several donations at once wait in a queue; while Steve is dead, events wait for him to respawn.

Chat commands

English only, one command per message, capital letters don't matter. [ ] means optional.

Donation events

Put a command at the start of your donation message and it happens in the game. No command — your message just shows up on screen.

Pick an event

Write its command first: !creeper, !give elytra. One wrong letter is forgiven in long names.

Or spin the roulette

!random any event of your tier, !good only good ones, !bad only bad ones.

The amount sets the tier

A tier unlocks all cheaper events too. Too little for the command — nothing happens. Some events have a rare stronger variant.

Tier prices in every currency

Map

Steve's coordinates are always in the corner of the stream. Open the world map, type them in, and see what's around him — villages, strongholds, biomes.

World map

The map is generated from the world seed, so it shows the world as it was created.
